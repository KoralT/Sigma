# Sigma Knowledge Base

This repository contains Sigma's foundational doctrine, operating model, platform architecture, product portfolio, and research knowledge.

## Knowledge Domains

- `DOC` — Foundational doctrine
- `OM` — Operating model
- `PA` — Platform architecture
- `PR` — Product portfolio and product specifications
- `RS` — Research and discovery
- `diagrams` — Shared diagrams
- `assets` — Supporting assets

```text
      ↙               ↘

Architecture        Portfolio
```

## Working Rules

1. Every concept has one authoritative source document.
2. Other documents reference the source instead of duplicating it.
3. No new strategic thinking is introduced while the knowledge base is being organized.
4. Content is populated only from approved existing material.
5. Foundational documents define the frame; supporting documents provide depth.
