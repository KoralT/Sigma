## Governance

- Every document must have a unique ID and a single parent document.
- Foundational documents define concepts and architecture.
- Supporting documents extend—but never redefine—their parent.
- Cross-references are encouraged; ownership remains with the parent document.
- ARC-001 serves as the conceptual entry point to the Sigma Knowledge Base and should remain aligned with all foundational documents.
