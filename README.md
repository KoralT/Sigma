# Sigma

Sigma's shared product knowledge base and Company Brain.

## Start here

The canonical working knowledge lives under [`Sigma-Knowledge-Base/`](Sigma-Knowledge-Base/).

Recommended entry points:

1. [`Sigma-Knowledge-Base/START-HERE.md`](Sigma-Knowledge-Base/START-HERE.md) — primary navigation and orientation.
2. [`Sigma-Knowledge-Base/COMPANY-BRAIN-GUIDE.md`](Sigma-Knowledge-Base/COMPANY-BRAIN-GUIDE.md) — how to work with the Company Brain, how to ask questions, how to interpret authority/status, and role-based usage.
3. [`Sigma-Knowledge-Base/COMPANY-BRAIN-GUIDE-HE.html`](Sigma-Knowledge-Base/COMPANY-BRAIN-GUIDE-HE.html) — Hebrew RTL companion guide for convenient distribution and reading.
4. [`Sigma-Knowledge-Base/CURRENT-STATE.md`](Sigma-Knowledge-Base/CURRENT-STATE.md) — current Sigma Product Truth and current-state picture.
5. [`Sigma-Knowledge-Base/05-DECISIONS/DECISION-LOG.md`](Sigma-Knowledge-Base/05-DECISIONS/DECISION-LOG.md) — current and superseded product/architecture decisions.

## Working rule

`main` is the only active branch and the current source of truth. The approved Company Brain v1.0 baseline is preserved by the `company-brain-v1.0` tag. Future learning should be added as new commits to `main` rather than rewriting historical decisions.

## Principle

The Company Brain should make it possible for a new contributor to understand:

- what Sigma is trying to achieve,
- what is true today,
- what is decided,
- what is still open,
- who owns what,
- and what should happen next.

For detailed guidance, start with [`Sigma-Knowledge-Base/START-HERE.md`](Sigma-Knowledge-Base/START-HERE.md) and [`Sigma-Knowledge-Base/COMPANY-BRAIN-GUIDE.md`](Sigma-Knowledge-Base/COMPANY-BRAIN-GUIDE.md).
